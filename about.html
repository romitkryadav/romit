The Person Behind The Code

About Romit

Curious builder, self-driven learner, and web enthusiast passionate about building fast tools and sharing practical knowledge.

My Story & Journey

I began my journey exploring how the web works from the ground up. Over time, that curiosity evolved into building small, focused utilities designed to eliminate tedious repetitive work for developers, marketers, and creators.

I believe in learning in public: testing hypotheses openly, publishing technical SEO audits, writing about code bugs and refactoring decisions, and being candid about ideas that didn't pan out.

When I'm not writing code or analyzing crawl trees, I enjoy long tea walks, reading non-fiction, exploring photography, and contributing to open-source discussions.

Core Principles

01
Immediate Value Without Friction Every utility I build should solve the user's task in one click with zero mandatory signup walls.
02
Performance & Zero-Bloat Lightweight payloads, edge caching, and 100/100 Lighthouse performance metrics are non-negotiable.
03
Radical Public Learning Failures are as valuable as wins. Documenting bugs and SEO algorithm updates helps the entire developer community.
